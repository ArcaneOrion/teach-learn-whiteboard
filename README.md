# 共写白板 · 安卓学习工具

一个装在安卓手机/平板上的本地白板应用。你在板上写字、画图，AI 也在同一块板上写讲解、出题、批注；
你可以直接在它写的东西上圈画，而它能看见你圈了什么。

> **当前状态：设计阶段（v0.2 草案），还没有代码。**
> 项目目录里目前只有文档，这是刻意的 —— 先把要做什么、为什么这么做写清楚，再动手。

## 四句话总结

1. **形态**：共写画布 —— 板是唯一界面，AI 说的话直接写进板里，不做「聊天框 + 白板」两栏。
2. **技术**：只用 TypeScript 一种语言。Web 技术画白板，`@earendil-works/pi-ai` 接 AI，Capacitor 打包成安卓 App。
3. **数据**：一切以「只追加的事件日志」为唯一真相 —— 同步、撤销、学习记录都从它白拿。
4. **组织**：**板 = 主题**（长期），**会话 = 一次坐下学习**（有始有终），两者正交。
   截图和会话数据全部留在本地、可关键词检索；**整个 App 不要任何危险权限，装完不弹框**。
   （前提：数据只存在 App 专属目录，且不用 Capacitor 的 `Directory.Documents`。代价是**卸载即删**，所以导出备份是必需功能。）

> 🔲 **记忆系统已改为暂缓**，只在代码里留好接口，v1 不实现。

## 开发命令

```bash
pnpm install     # 装依赖（只需一次）
pnpm dev         # 启动开发服务器 ← 日常开发用这个，输出里有一行局域网地址，手机可直接打开
pnpm test        # 跑单元测试
pnpm typecheck   # 只做类型检查
pnpm build       # 类型检查 + 打包成 dist/
```

**日常开发就是 `pnpm dev`**，改代码浏览器自动刷新，不用每次重新构建。

### 同步服务

```bash
pnpm sync-server                                     # 起在 8787，数据存 ./sync-data.json
pnpm sync-server --port 9000 --token 你的口令         # 换端口 / 加口令
```

然后在 App 里点「💾 数据」→ 填地址 → 立即同步。
多台设备填同一个地址就能互相对上。**同步是合并**，两边写的东西都会留着。

⚠️ 这个服务是**给你自己用**的：没有账号体系、数据是明文 JSON。
只在自己机器 / 局域网里跑，别直接暴露到公网。要公网用就加 `--token` 再套一层 HTTPS 反代。

### 出怪事时先试这个

**改了代码但页面行为没变、或者报「某某函数不存在」** → 重启 `pnpm dev`。

踩过的坑：Vite 的**模块转换缓存**有时不会跟着文件改动失效（文件监听漏了），
于是浏览器拿到的是「编辑做到一半」的版本 —— 表现为一半是新代码一半是旧代码，
报错信息完全对不上源码。**这时候刷新页面没用，必须重启 dev server。**
