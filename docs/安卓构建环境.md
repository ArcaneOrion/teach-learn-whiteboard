# 安卓构建环境

> **现状**：本机**没有 Java、也没有 Android SDK**，所以现在**打不出 APK**。
> 网页部分（M0 的墨迹层）不受影响，已经能跑、能验证。

---

## 先做这个：手机上立刻能试

开发服务器支持局域网访问，**你的安卓手机现在就能打开**：

```bash
pnpm dev
# 输出里会有一行 Network: http://192.168.x.x:5173/
```

手机连同一个 Wi-Fi，浏览器打开那个地址，就能**用手指在真机上写字**，
HUD 会实时显示 `设备 touch`。

**这能在装任何安卓工具链之前，就把"真机触摸体验"验证掉。**
别跳过这一步 —— 它几乎零成本，却能立刻告诉你「这条路手感行不行」。

---

## 要打包成 APK，需要补两样东西

| 需要 | 为什么 |
|---|---|
| **JDK 21**（或 17） | Gradle 要它来编译安卓工程 |
| **Android SDK**（platform + build-tools） | Capacitor 生成的安卓工程依赖它 |
| `adb` | 可选，用来装到手机上调 |

---

## 你是 NixOS，两个方案

### 方案 A（推荐）：项目内自带一份

在**本项目根目录**新建 `shell.nix`：

```nix
{ pkgs ? import <nixpkgs> { } }:

pkgs.mkShell {
  packages = with pkgs; [
    jdk21
    gradle
    android-tools                      # adb 等
    (androidenv.androidPkgs_9_0.androidsdk.override {
      # 只装用得上的部分，能少下载很多
      includeSystemImages = false;
      includeEmulator = false;
    })
  ];

  env = {
    ANDROID_HOME = "${pkgs.androidenv.androidPkgs_9_0.androidsdk}/libexec/android-sdk";
    JAVA_HOME = "${pkgs.jdk21}";
  };
}
```

用法：

```bash
nix-shell          # 进入环境
java -version      # 应该能看到 21
echo $ANDROID_HOME # 应该有值
pnpm cap add android
pnpm cap run android
```

**优点**：项目自包含、能提交进 git，不污染别的项目。

### 方案 B：加到现有的共享 flake

你的 `/home/arcaneorion/AI/Agent-workerspace/flake.nix` 里已经有
`nodejs_24`、`pnpm_10` 等。可以在 `packages` 里加上 `jdk21`、`gradle`、
`androidenv.androidPkgs_9_0.androidsdk`。

**优点**：所有项目共享，`node` 和 `java` 在一起。
**缺点**：会影响别的项目，而且那个 flake 不在本仓库里，改动不进版本管理。

## ⚠️ 两个注意

1. **首次下载约 1.5~3 GB**（Android SDK 很大）。你现在磁盘剩 45 G，够用，但要有心理准备。
2. **上面 nix 表达式里的属性名我没能验证** —— 本机的 Nix fetcher 缓存在沙箱外只读，
   我跑不了 `nix eval`。**第一次 `nix-shell` 如果报"attribute not found"**，
   用这条命令查真实属性名：

   ```bash
   nix search nixpkgs androidenv
   nix search nixpkgs androidsdk
   ```

   nixpkgs 里 Android SDK 的属性名（`androidPkgs_9_0` 这类）**换版本会变**，这是已知情况。

## 备选：装 Android Studio

如果不想碰 Nix，也可以直接装 Android Studio —— 它自带 SDK 管理器、模拟器和 adb，
图形界面，对新手更友好。代价是更重（几个 GB），而且和你的 Nix 工作流是两套东西。

## 顺序建议

1. **现在**：`pnpm dev`，手机浏览器打开局域网地址，用手指试手感
2. 觉得手感可以 → 再补 JDK + Android SDK，做 Capacitor 打包
3. 手感不行 → 正好，还不晚，逃生门是换原生低延迟墨迹视图（技术文档 §5.5）

**先验证手感，再投入几个 GB 装工具链** —— 这个顺序能帮你省下大量时间。
