模型渠道

Key 只存在这台设备上，不会上传。 这个 App 里没有上传 Key 的代码 —— 请求直接从你的设备发给模型厂商。
目前没有内置任何渠道：需要你自己填一个（任何 OpenAI 兼容的端点都行）。

添加一个渠道

任何 OpenAI 兼容的端点都能填。本机服务（如 Ollama）也可以， 但需要安卓端放行明文 HTTP（见 docs/技术开发文档.md §7.4）。

记录

数据与备份

你的数据全部在这台设备上，我们没有服务器。
但要注意：卸载 App 会把它们一起删掉。 所以建议定期导出备份 —— 尤其是你不想丢的学习记录。

备份文件里不含 API Key —— Key 只留在这台设备上，恢复后要重新填一次。

存成图片

把当前这块板存成一张 PNG —— 内容和你画的笔迹都在里面， 可以直接发给别人、贴到笔记软件里、或者打印。

同步

在一台你自己的机器上跑 pnpm sync-server，把地址填到这里， 多台设备就能互相对上。同步是合并 —— 两边写的东西都会留着。
⚠️ 截图不参与同步（图片太大，图片本体不进事件日志）—— 别的设备能看到"这里拍过一张截图"，但看不到图，重新拍一张即可。

不可撤销。清空前请先导出备份。

资料

导入之后，AI 会在需要时自己去查这些资料，把查到的原文写到板上。
支持 .txt / .md / .pdf。PDF 第一次导入会先下载解析库（约 1.7 MB，只下一次）。
扫描版 PDF 读不出文字 —— 那种整页是图片，得走视觉识别，还没做。

资料只在这台设备上，不同步，也不进备份 —— 原文件你自己有，换设备重新导入即可。

板

一块板 = 一个主题。点一行就能切过去，笔迹和内容都各自留着自己的。
切换不会新开一次学习 —— 同一次学习里可以翻好几块板。
